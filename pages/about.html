About me

This website is my project for my Web Development exam. I built it using only HTML, CSS and vanilla JavaScript, with no backend, database or API.

About Jade

The name Jade is inspired by my nickname, Jed, and the gem in the logo stands for something precious: your privacy. Jade is a privacy-focused social media prototype. People can post, share photos, comment, send messages and even comment secretly, all while their data stays in their own browser.

What I used

HTML for structure, CSS (flexbox, box model, external stylesheet) for the layout and design, and JavaScript with localStorage to make it work like a real app.
